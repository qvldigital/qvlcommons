`MatchCard` is the atom of Spielplan, Ergebnisse and the team dashboard.

```jsx
<MatchCard date="Sa 14.11." time="14:00" level="B" region="Nord"
  home="Berlin Bumpers" away="Hamburg Hurricanes" homeSets={3} awaySets={1}
  status="gespielt" sets={["25:21","23:25","25:19","25:17"]} />
```

Never add a hall name, address or map link to this card.
