The volleyball mark, the only brand-owned graphic icon, extracted from the supplied CI backgrounds in four colourways. Use it through `BallIcon` (`tone="petrol" | "petrol-dark" | "orange" | "white"`) and as the spot graphic in `EmptyState`.

- `ball-petrol.png` on light grounds (`surface-card`, `surface-page`).
- `ball-petrol-dark.png` where the petrol mark needs more weight on pale tints.
- `ball-orange.png` as an accent mark on petrol or night.
- `ball-white.png` on `surface-inverse` (petrol) and on net artwork.

UI glyphs are Lucide, set through `Icon`, not files here. No emoji, no icon font.
