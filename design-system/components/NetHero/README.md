`NetHero` is the page opener on queerleague.de. Use the supplied artwork — never regenerate or redraw the net.

```jsx
<NetHero background="grey-petrol" eyebrow="Saison 2026/27" title="Volleyball, wie es sein soll"
  lead="Rund 1.000 Mitglieder, Levels A–D, fünf Regionen — und Platz für dich."
  actions={<Button variant="accent" size="lg">Team anmelden</Button>} />
```

One hero per page. Keep the headline in the image's empty area (upper left); the net occupies the lower right.
