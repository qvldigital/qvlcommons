The island illustrations, supplied on 06.11.2026 (website, cloud, forms) and 20.11.2026 (newsletter, community, mail) for the DV 2026 deck. Originals live in `../../../assets/illustrations/`.

Every motif stands on the same island: a chamfered petrol-mid plate with a petrol block shadow and pale-petrol waves underneath. One object per island, flat CI colours only, no gradients, no vendor logos or vendor colours.

| File (`qvl-illu-island-<name>.svg/.png`) | Shows | Use for |
|---|---|---|
| `website` | browser window with the ball in the hero, orange price tag | website, hosting |
| `cloud` | documents syncing with a cloud, orange price tag | file storage, SharePoint, cloud services |
| `forms` | clipboard with checkboxes and pen, orange price tag | forms, registrations |
| `newsletter` | issue with the ball, small envelopes flying out | newsletter, mailings to everyone |
| `community` | two speech bubbles, one with a group of three, typing badge | community chats (e.g. WhatsApp communities) |
| `mail` | single envelope with an orange @ tile | e-mail in general |

- The orange price tag (€ with an up arrow) stands for rising costs. It belongs to the first three motifs only; do not add it elsewhere without that meaning.
- PNGs are 1200 × 1200 px with a transparent background; the SVGs are the masters and use no fonts.
- Place several islands side by side and slightly offset to show separate systems ("Insellösungen").
- Never recolour into vendor colours (no WhatsApp green, no Microsoft blue). Illustrations are spot graphics for slides, mails and empty pages, not UI icons; UI glyphs stay Lucide through `Icon`.
