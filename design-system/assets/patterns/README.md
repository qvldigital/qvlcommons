Icon-net patterns supplied as PNG: a wavy net grid with icons sitting in the meshes. Used as section bands behind a white plate via `PatternBand`; never redraw or extract the icons as UI icons.

- `pattern-documents-info.png` for rules and downloads (`PatternBand pattern="documents"`).
- `pattern-table-medal.png` for results, tables and Wall of Fame (`pattern="table"`).
- `pattern-pads-cards.png` for referees and equipment: knee pads, cards, whistle (`pattern="gear"`).

Text on a pattern always sits on a solid or near-solid white plate (`PatternBand plate`).
